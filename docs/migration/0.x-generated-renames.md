# 0.x renames and the `options()` behaviour change

Pre-1.0 breaking changes and how to update. All of these landed while the version was `0.x`; SemVer allows breaking
changes in any `0.x` release (see the [compatibility policy](../compatibility-policy.md)).

## Symbol renames

| Before | After | Why |
| --- | --- | --- |
| generated root (earlier name) | `OpenRouterClient` | The generated root client is `OpenRouterClient`; the curated `OpenRouter` facade wraps it. Construct `OpenRouter { … }` / `OpenRouter(credential, httpClient)` as before — the facade is the supported entry point. |
| `OpenRouterBuilder.trustHost(...)` | `OpenRouterBuilder.trustOrigin(origin)` | Trust is scoped to a parsed **origin** (scheme + host + port), not a bare host string, matching the trusted-host validation used for credential attachment and pagination. |
| `client.betaResponses` / `BetaResponsesClient` | `client.responses` / `ResponsesClient` | Responses reached GA at the 2026-08-29 contract re-pin (`b901d462…` → `b2a4948a…`); the `beta.*` tag was removed upstream. |
| `client.betaAnalytics` / `BetaAnalyticsClient` | `client.analytics` / `AnalyticsClient` | Analytics reached GA at the same re-pin; the beta client folded into `AnalyticsClient`. |

Replace the old names with the new ones — the behaviour is otherwise unchanged.

## `options()` no longer required for client defaults

Client-level retry, deadlines, and observers now reach **every** call automatically (ADR 0022). Previously a call
made without `options` did not retry; you had to pass `options = client.options()` to opt into client behaviour.

```kotlin
// Before: options() was required to get client defaults on a call.
client.chat.sendChatCompletionRequest(request, options = client.options())

// After: client defaults apply with no options; pass options { } only for per-call overrides.
client.chat.sendChatCompletionRequest(request)
client.chat.sendChatCompletionRequest(request, options = client.options { retry(RetryPolicy(maxAttempts = 5)) })
```

`OpenRouter.options { … }` is now **per-call overrides only** (plus per-call pagination bounds, which are not part of
the client config). A field left untouched inherits the client value; a per-call `retry`/`deadlines` override wins.
