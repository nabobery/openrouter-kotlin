# Compatibility reports

Every spec/API change — each drift PR and each release — commits a **layered compatibility report** here,
named `<date>-<from8>-to-<to8>.md` (e.g. `2026-08-30-b2a4948a-to-e88b0cec.md`). The report is generated by
`scripts/compat-report.py` from a before/after snapshot captured by `scripts/compat-snapshot.sh`.

## What a report is

The change is classified independently on **seven layers**, and the release classification is the **worst**
layer over `patch < minor < breaking < unclassified`:

| Layer | Signal | `patch` | `minor` | `breaking` | `unclassified` |
| --- | --- | --- | --- | --- | --- |
| OpenAPI source | `oasdiff breaking`/`changelog` JSON | no breaking, no changelog | changelog-only (INFO) | any `oasdiff breaking` entry (both `ERR` **and** `WARN`) | oasdiff unavailable **and** spec bytes differ |
| Semantic | `manifest.json` digests + `sdkgen diff` `apiImpact` | all four digests equal | `apiImpact ∈ {none, non-breaking}` | `apiImpact = breaking` | `potentially-breaking`, or digests changed with no `sdkgen diff` |
| Kotlin source | `sources.txt` (per-file sha) | unchanged | added/changed, none removed | any generated file removed | — |
| JVM ABI | `sdk.api` line diff | unchanged | only `+` lines | any `-` line | present on only one side |
| klib ABI | `sdk.klib.api` line diff | unchanged | only `+` lines | any `-` line | dump missing on one side |
| Wire + behaviour | `tests.json` | goldens + jvmTest passed | — | either failed | either unavailable |
| Targets | klib `Targets:` header | same set | targets added | targets removed | — |

A layer whose inputs are entirely absent is reported as **`unavailable`** (never silently "no change") and does
not gate; a layer that detects a change it cannot classify is **`unclassified`** and **does** gate.

## Exit-code contract (the gate)

- `patch` / `minor` → **exit 0** (allowed).
- `breaking` → **exit 3** — allowed pre-1.0 only with the `compat:breaking` PR label and a written rationale
  (see `docs/compatibility-policy.md`).
- `unclassified` → **exit 1** — a release blocker: a layer changed in a way the rules cannot classify. Fix the
  input (capture the missing dump, run oasdiff, provide the `sdkgen diff`), never the rule, unless the rule is
  genuinely wrong (then change the rule **and** its test together).

## How to read one

Each report lists one row per layer with its classification and the concrete evidence (digest equality, ABI
line counts, target set, test outcomes), then the overall **Release classification** line. The classification
drives the release/label decision; the per-layer rows show *why*.
